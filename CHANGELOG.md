# Changelog

All notable changes to Zenit Gold are documented here.

## 2.2.1 — 2026-10-30

### The banner behind the whole app

- The banner now runs continuously behind the chat, channel list and member list.
- Removed the extra banner strip above the header.
- Chat and sidebars are tinted glass instead of nearly opaque black.
- Added `--zg-chat-alpha`, `--zg-sidebar-alpha`, `--zg-members-alpha`, `--zg-panel-alpha` and `--zg-input-alpha` for easy adjustment.
- Fixed current Discord class selectors for selected channels, unread channels, mentions and the member list.
- Added a light text shadow on messages and headers for readability on bright artwork.
- Popouts and modals stay more opaque so text remains readable.

## 2.1.1 — 2026-10-30

- First public packaging of Zenit Gold.
- Black and gold colour system, banner, mascot watermark, gold buttons, badges and scrollbars.
- Single-file theme for BetterDiscord and Vencord.
